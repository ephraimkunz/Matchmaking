Numeric parameters
target_shortlist 5
The ideal length of each person's shortlist.
max_appearances 8
The maximum number of shortlists someone should appear on.
max_appearances_relaxed 10
The appearance cap ceiling when the pool is tight. The algorithm raises the cap one at a time from max_appearances up to this limit whenever a pass stalls. Should always be larger than max_appearances.
rng_seed
Optional. Pin the RNG seed for reproducible runs. Leave empty to seed randomly.
Toggles
sort_shortlists_by_score Sorts each shortlist by descending score so best matches appear at the top. If off, shortlist order is random.
print_scores Print the match score next to each match name in the output.
collect_diagnostics Collect and display diagnostic statistics about the matching run.
